# Forslag til brukergrensesnitt

Visuelle utkast til Stadionhopper, basert på brukerundersøkelsen.
Forslagene skal diskuteres og godkjennes av gruppa.

## Legge til kamp
Alle innloggede brukere kan legge til kampinformasjon.
Dette gjør at fans kan bidra uten at klubben må administrere alt.
