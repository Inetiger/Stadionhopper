# Stadionhopper

Stadionhopper gjør det enklere å oppdage fotballkamper, utforske stadioner og få oversikt over arrangementer.

## Åpne Stadionhopper

Bruk appen direkte i nettleseren: https://inetiger.github.io/Stadionhopper/

Du trenger ikke å laste ned eller installere noe.

## Om demoen

Den publiserte demoen bruker fiktive eksempeldata. Du kan utforske kampoversikten og stadioninformasjonen uten å logge inn.

Innlogging, personlig historikk og lagring av innsjekkinger er ikke tilgjengelig i den publiserte demoen.
